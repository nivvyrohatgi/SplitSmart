# SplitSmart — Dart Expense Splitter

SplitSmart is a beginner-friendly expense management program written in Dart. It helps groups track shared expenses and calculate how much each member owes or should receive.

## Features

- Add group members with unique names.
- Record expenses with a title, amount, payer, category, and participants.
- Split expenses equally among selected participants.
- List all recorded expenses.
- Filter expenses by member or category.
- Calculate each member's total paid, total share, and net balance.
- Validate duplicate members, invalid amounts, unknown members, and empty participant lists.

## Technologies

- Dart
- DartPad for writing and running the program

## How to Run

1. Open [DartPad](https://dartpad.dev/).
2. Copy the contents of `main.dart` into the editor.
3. Click **Run** to execute the program and view the output.

## Example

If Asha pays ₹900 for dinner shared equally by Asha, Ravi, and Neha:

- Asha pays ₹900 and owes ₹300 as her share.
- Ravi owes ₹300.
- Neha owes ₹300.
- Asha should receive ₹600 from the other members.

## Learning Objective

This project demonstrates Dart classes, objects, lists, methods, loops, conditional statements, input validation, and basic expense calculations.
